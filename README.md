# Minha Loja - Informática Top

Aluno(a): Pedro Cartaxo Dantas - 2026120016

Função: 

1. listarProdutos: lista todos os produtos da loja
2. cadastrarProdutos: cadastra novos produtos na lista
3. calcularValorEstoque: calcula o valor total em estoque
4. buscarProduto: faz uma busca para o produto desejado
5. produtosEmFalta: informa a quantidade de produtos com quantidade abaixo do mínimo
6. aplicarDesconto: aplica um desconto a certa categoria de produtos
7. venderProduto: faz a venda de um produto
8. registrarVenda: registra uma venda
9. formatarNome: formata o texto indicado
10. converterParaJSON: converte a lista para JSON
11. lerJSON: lê a lista convertida em JSON, transformando-a denovo em objeto
12. gerarRelatorio: gera um relatório da loja
